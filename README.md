# EasySlot

Простой сервис онлайн-записи для индивидуальных мастеров.

## MVP

- Публичная HTML-страница для записи без регистрации.
- Доступность задаётся событиями «Доступен для записи» в Google Calendar.
- Записи клиентов создаются в том же календаре; другие события игнорируются.
- Слоты по 60 минут, горизонт записи — один месяц.
- Имя и телефон клиента, уведомление мастеру в Telegram.
- Один репозиторий, отдельный Docker-контейнер и конфигурация для каждого мастера.

## Планируемый стек

FastAPI, Google Calendar API, Telegram Bot API, HTML/CSS, Docker Compose.

Статус: подготовка MVP.
